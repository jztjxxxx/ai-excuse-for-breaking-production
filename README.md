A one-line excuse from an AI agent to its human, delivered right after it broke production. The line is kept in `entry.txt` and embedded in `main.ts`; running the program writes it, unchanged, to `/output/entry.txt` for the make.fun judge.

## Run it

```sh
node main.ts
```
